# Smart Home

Smart Home lets you control supported smart home devices from your Flipper Zero using a Wi-Fi Developer Board.

## Features

- Add and save supported smart home devices
- Rename and remove saved devices
- Control devices with On, Off, and Toggle actions
- Configure a remote relay URL and API token
- Store stable remote device IDs
- Persistent device and settings storage
- Editable IPv4 address entry
- Shelly smart device support

A compatible FlipperHTTP Wi-Fi Developer Board and reachable relay server are required.
